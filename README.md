# coldchain

de-hotlinker for your site idfk

the thing scans your project directory for any and all image tags and replaces any external hotlinked images with local ones!

written in typescript (ts type shit ts ts ts ts ts ts ts)

---

## how to use
(insert picture of former united states president joe biden here with the capti9on biden blast)

### npm

make sure you have npm installed

run `npm i coldchain`

### manual

clone this repo

cd into the repo directory

npm link

now you can do `coldchain <project-dir>`
